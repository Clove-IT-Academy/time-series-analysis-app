# Synthetic examples

Generated with NumPy seed 42; no real client data.

- monthly_transactions.csv: 84 months, two transactions/month, sales and purchases; use transactions, sum, MS, period 12.
- weekly_summary.csv: weekly summaries labeled Monday; use summary, W-MON, seasonal period 1, validation 8.
- ambiguous.csv: generic numeric labels; explicitly choose target meaning.
- short.csv: insufficient history demonstration.
- business_examples.xlsx: transaction and weekly summary worksheets, requiring explicit selection.

Data are illustrative; model winners and future accuracy are not guaranteed.
